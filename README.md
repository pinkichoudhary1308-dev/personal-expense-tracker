# Personal Expense Tracker

A full-stack Personal Expense Tracker application built using React.js, Spring Boot and MySQL.

The application allows authenticated users to manage their income and expenses, view financial summaries, filter and sort transactions, and securely access their own transaction data.

## Features

- User Registration
- User Login and Logout
- JWT Authentication
- Protected Routes
- Dashboard
- Add Income
- Add Expense
- Edit Transaction
- Delete Transaction
- Transaction Filtering
  - All
  - This Week
  - This Month
  - This Year
  - Type
  - Category
  - Date
- Transaction Sorting
- Pagination
- Total Income
- Total Expense
- Balance
- Income vs Expense Chart
- Recent Transactions
- Input Validation
- Error Handling
- Responsive Design for Desktop and Mobile
